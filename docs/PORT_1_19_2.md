# Experimental Forge 1.19.2 adaptation

The native adaptation is in `../forge-1.19.2/`. It is an experimental partial port, not a complete replacement for the original mod and not compatible with 1.7.10 saves.

Start with:

- `../forge-1.19.2/docs/GETTING_STARTED.md` — installation, controls, configuration and build commands.
- `../forge-1.19.2/docs/PORT_STATUS.md` — exact implemented systems, simplifications and major missing features.
- `../forge-1.19.2/docs/VALIDATION.md` — actual build, unit, in-game and runtime verification.

Use the separate build inside `forge-1.19.2`. The root project, its source and its Gradle wrapper remain the original 1.7.10 project. Install only the `electrical-age-1.19.2-0.1.0-port-all.jar` built by the native project.
