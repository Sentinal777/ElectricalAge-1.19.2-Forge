Electrical Age / BuildCraft Community Edition compatibility

Audited BCCE tag 8.0.23, commit 23c6af379676ce5262c5c0cb6f1f331edc9b12c6; published CurseForge file 9035804 for Minecraft 1.19.2 Forge. ELN target Forge is exactly 43.5.0 and Java 17. No BCCE source changes were made.

HISTORICAL COMPARISON
The exact Electrical Age 1.24.6 reference has a generic registered “fuel” heating-value entry explicitly identified as BuildCraft fuel, generic inventory/fluid interactions, and RF/IC2/OpenComputers energy converter firewalls. The inspected pinned source does not contain an active direct BuildCraft MJ integration class. “MJ” on its meter is a displayed energy unit, not proof of BuildCraft API linkage. The modern native MJ bridge is an added equivalent adapter, not a claimed port of a nonexistent direct MJ class in this baseline.

CONVERSION AND CAPABILITIES
Both directions share one fractional FE buffer. Mode and enabled state determine which capabilities accept/provide energy; receive and extract cannot be used simultaneously. Simulations leave state untouched. Repeated calls share the same per-game-tick budget. Buffer, electrical input/output limits and configured efficiency bound exchange. MJ conversion reads BuildCraftApi's conversion service (default 1 MJ = 10 FE), using micro-MJ as the API requires. Sub-FE MJ remainders are returned rather than invented or silently credited. FE scale defaults to 1 FE/J and efficiency to 0.95 per direction. Accounting tests cover fractional energy, repeated transfer limits, simulate versus execute and persistence.

LIMITS
Native MJ linkage is enabled only for version 8.0.23 (including its +1.19.2+forge suffix). Other BCCE versions can use standard FE if configured, but are unverified and native adapter linkage is disabled. The audited API is internal rather than a stable general cross-version ABI. No promise of all BCCE gates, robots, power pipes, refineries, machines or other mods working. Complete original fluid/heat machinery and processing progression are not present. Integration is functional for tested assemblies and remains partial overall.
