Electrical Age 0.3.0 preview — Windows 11 installation and build

This is a partial experimental port. Use a new isolated game directory and test world. Existing Minecraft installations, mods, settings and personal worlds were not modified during development.

INSTALL
1. Install Java 17 and Minecraft 1.19.2. Download Forge 1.19.2 version 43.5.0 from https://files.minecraftforge.net/net/minecraftforge/forge/index_1.19.2.html . Select 43.5.0 explicitly.
2. Create a separate launcher profile with its own game directory and Java 17 executable. Launch the new Forge profile once, then close it.
3. Copy ElectricalAge-1.19.2-0.3.0-preview.jar into that profile's mods folder. Install one ELN JAR only. The delivered JAR embeds Kotlin 1.9.22 and Commons Numbers 1.2 using Forge Jar-in-Jar; no separate Kotlin-for-Forge installation is needed.
4. Optional BuildCraft: install exactly BuildCraft Community Edition 8.0.23 for Minecraft 1.19.2 Forge, file 9035804:
   https://www.curseforge.com/minecraft/mc-mods/buildcraft-community-edition/files/9035804
   Filename: BuildCraft-Community-Edition-8.0.23+1.19.2+forge.jar.
   Do not install the legacy 1.7.10 BuildCraft mod. BCCE is not bundled in ELN. Native MJ support activates automatically for the audited version, including its default MJ_ONLY mode. Other versions were not verified.
5. Launch and create a new creative test world. Open the Electrical Age creative tab. Server and client must use the same ELN build and Forge 43.5.0. A dedicated server can use the same delivered JAR.

BASIC CONTROLS AND TEST CIRCUIT
• Mount a component by right-clicking a solid surface. Small components can share up to six mounting faces; large machine parts use their own carrier block.
• Use a wrench to rotate, sneak-right-click with it to remove a selected part. Empty-hand right-click opens relevant settings and live measurements. Click switches/breakers to toggle/reset; sneak-click opens their settings.
• Floor-mounted rotation-zero pin ordering: east 0, south 1, west 2, north 3. Bipolar electrical devices normally use 0/2; shaft devices use 1/3. Rotate electrical parts as needed. A source → cable → resistor → ground circuit needs the resistor's terminal orientation to match the run.
• For a simple QA circuit, put a 50 V Electrical Source, Low Voltage Cable, 100 Ω Power Resistor and Ground Cable in an east-west row on supported floor blocks. Rotate the resistor twice. A live multimeter/readout should show about 0.5 A, with a small cable drop. Removing the cable stops the current. Electrical Source is an experimental creative supply rather than a finite survival generator.
• Machines have input/output slots and consume simulated power or shaft energy. Automated insertion uses top/sides; extraction uses the bottom. Recipes reject unrelated inputs. Mechanical rollers use plate recipes.
• Energy Converter has a direction button: electrical → BuildCraft/FE exports; BuildCraft/FE → electrical imports. It must be enabled and connected to a closed electrical circuit. Importing mode requires actual buffered FE/MJ and has a finite power limit.
• Digital Display accepts “minimum,maximum” in its field. Value input is pin 2, dots pin 0, strobe pins 1/3. Right-click with dye changes digit color.
• Shafts and gas/steam machines report angular speed and energy; fuel equipment reports stored fluid. Place shaft ports in matching directions and supply starting shaft speed for the gas turbine.

CONFIGURATION
Forge generates config/eln-common.toml. Defaults:
integration.fePerJoule = 1.0
integration.conversionEfficiency = 0.95
integration.maxFeTransferPerTick = 1000
simulation.stepsPerTick = 10 (200 electrical steps per second at 20 TPS)
simulation.shaftOverspeedProtection = true
simulation.cableThermalProtection = true
simulation.cableVoltageProtection = true
network.measurementSyncTicks = 10
Restart after changing common configuration. Many old settings are not restored; ore rates currently come from generated data rather than a complete legacy worldgen config.

BUILD FROM SOURCE
1. Extract ElectricalAge-1.19.2-source.zip to a writable directory. Install JDK 17 and set JAVA_HOME to its installation directory.
2. Open PowerShell in ElectricalAge-development/forge-1.19.2, not the legacy root. Optional: set GRADLE_USER_HOME to a task-specific writable cache directory.
3. Run .\gradlew.bat build
   This downloads Gradle 8.8, ForgeGradle 6.0.54, Kotlin and Minecraft/Forge dependencies. It also fetches published BCCE for compile-only optional API linkage; BCCE is not installed by the normal run or embedded in the resulting JAR. Internet access is required on the first build. Do not upgrade the wrapper automatically.
4. Install build/libs/electrical-age-1.19.2-0.3.0-port-preview-all.jar. The thin JAR and sources JAR are not installable standalone artifacts.
5. Run .\gradlew.bat runGameTestServer for the 23 native Minecraft tests, or .\gradlew.bat runGameTestServer -PbcceIntegration for the 29-test suite using real published BCCE.
6. Run .\gradlew.bat runClient for normal development gameplay. -PclientSmoke adds QA-only code and the optional pacing agent; never use that switch when building the release JAR.
7. After a BCCE/client QA run, build normally again without either QA switch. The final release excludes BcceGameTests and ClientSmoke classes. Inspect the GameTest completion lines as well as the build exit code.
8. Python 3 is needed only for regenerating already-included content. Use .\gradlew.bat generateLangFiles -Ppython=C:/path/to/python.exe ; also run python tools/generate_worldgen.py for ore data. Normal build does not require Python.
9. Coverage regeneration: python tools/audit_legacy.py, then python tools/audit_coverage.py ../reference-1.24.6 . The literal inventory scans the recovered root; exact descriptor/source hashes scan the pinned reference. Core/resource migration scripts overwrite generated files and should only be run deliberately. The original root Gradle build remains unchanged.

TROUBLESHOOTING
• Missing Kotlin Intrinsics usually means a thin JAR was installed. Use the delivered preview JAR or the generated -all.jar.
• Wrong Forge version: install exactly 43.5.0 for 1.19.2. The mod metadata enforces that version.
• No current: check return/ground path, part rotation, switch state, cable ratings and generator fuel/shaft energy. FE does not replace internal electrical physics.
• “Circuit simulation paused”: retain the stack trace and smallest reproduction; changing topology retries the circuit.
• Some equipment is absent or simplified. Consult Feature-Coverage.txt and feature-coverage.json before treating this build as an original ELN replacement.
