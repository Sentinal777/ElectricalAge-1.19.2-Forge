# Verification record — 0.2.0

Environment: Java 17, Minecraft 1.19.2, Forge 43.5.0, ForgeGradle 6.0.54, Kotlin 1.9.22 and Gradle 8.8. These checks cover the implemented subset, not complete original-mod parity.

## Build and automated tests

The native project was built with `generateLangFiles build --offline` after dependency setup. All **168 JUnit tests passed with zero failures, errors or skipped tests**; totals are in `verification/unit-tests.json`. Coverage includes selected original MNA, expression, state-machine, battery and solar tests, shared-current regressions, native persistence, original geometry dimensions, frame handedness, legacy orientation compatibility, resource bindings and original tracker stops.

All 15 native Minecraft GameTests pass. They cover resistor circuits/disconnection, breaker trip/reset, furnace processing, macerator recipes, logic inputs, wireless channels, capacitor rebuilds, battery reload, floating series solar panels, flip-flop reload, sample-and-hold, mounted placement and support loss, aimed-part selection, signal-switch interaction, and machine processing/animation pause/resume. See `verification/gametest-result.txt`.

## Running client

A Java 17 Forge client opened the earlier 0.1.0 test world. A QA gallery instantiated all 111 component variants; the original models and textures rendered without OBJ-loading or block-entity-render exceptions. The original source screen artwork was checked interactively: applying 50 V to the saved 100-ohm circuit changed the displayed current from 0.25 A to 0.50 A. A powered furnace menu showed its input, produced iron output, power and processing state. Floor, wall and ceiling component orientations were also inspected. Screenshots are retained under `verification/`.

The tracker-angle correction was additionally checked after rebuilding, at noon and a later sun angle. The corrected tilt uses the original +/-45-degree stops and world sunlight direction.

The virtual-display environment has no audio device and cannot contact the Minecraft authentication services. Client rendering and an integrated creative test world ran; authenticated remote multiplayer and audio were not tested.

## Installable JAR

The reobfuscated `-all.jar` is checked on a standalone Forge 43.5.0 dedicated server, including bundled Kotlin/numerical dependencies, circuit current, disconnection and world saving. Exact readings and the tested non-documentation payload fingerprint are in `verification/production-runtime.json`. A documentation-only final repack is required to retain that same runtime payload. The final artifact hash is recorded in the source archive's `verification/final-artifact.json`, which is deliberately excluded from the JAR to avoid a self-referential hash.

## Original source and assets

Every file from the uploaded source archive is retained. Original source, resources, build files and wrapper are unchanged; only AGENTS.md has the previously required sandbox notes. The independent native project contains 122 Java/Kotlin production source files. The migration retains 1,222 runtime resource entries, including all 163 indexed OBJ files. Every one of its 780 PNGs is byte-identical to its original source. Modern resource paths are normalized; mesh positions, normals and UVs are preserved.

All 111 component icons resolve to original textures. Assigned models and selected groups resolve. Ten cable variants use procedural geometry with original textures; the FE converter uses its original block-side texture; no implemented non-cable component uses placeholder geometry. These asset counts exceed the implemented feature set and do not imply all original assets are used in gameplay.
