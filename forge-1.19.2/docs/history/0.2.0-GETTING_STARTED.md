# Install and use the experimental 1.19.2 port

Read `PORT_STATUS.md` first: this release implements a subset of Electrical Age and cannot load legacy 1.7.10 Electrical Age worlds.

## Installation

1. Create a Minecraft **1.19.2** Forge profile with **Forge 43.5.0** and **Java 17**.
2. Put **`electrical-age-1.19.2-0.2.0-port-all.jar`** in its `mods/` folder. The `-all.jar` includes Kotlin and the numerical library through Forge Jar-in-Jar. Do not install the thin JAR or the sources JAR, and do not install both Electrical Age JAR variants.
3. For a server, use the same Forge version and the same `-all.jar` on both the client and server.
4. Existing native 0.1.0 test worlds can be opened; saved terminal directions are retained. Client and server must both be updated to 0.2.0. Start with a creative test world and find the Electrical Age creative tab. Existing 1.7.10 worlds require a migration system that has not been implemented.

No separate Kotlin-for-Forge mod is required by this build. Other Forge 43.x releases at or above 43.5.0 are allowed by metadata but only 43.5.0 was verified.

## Basic controls

- Right-click a solid surface with a component to mount it. Machine components occupy their own block; small components can occupy six mounting faces of one carrier block.
- Right-click a component with an empty hand to open its configuration and live readout. Apply sends settings to the server.
- A wrench rotates the selected component. Sneak-right-click with the wrench removes that component. In creative mode, wrench removal does not drop an item.
- Right-click switches and breakers to toggle/reset them. Sneak-right-click opens their configuration. A button produces a short pulse.
- Right-click with the multimeter or thermometer for a quick measurement.
- Machine menus expose one input and one output slot. Hoppers/other item handlers can insert input and extract output.

Voltage source, current source and most signal outputs are referenced to a common electrical ground. Power resistors, capacitors, inductors, batteries, solar panels, switches and transformers use opposing terminals. A closed circuit needs a return path. A ground cable explicitly connects a node to the reference; it is useful for experimental circuits.

For floor-mounted components at rotation zero, terminal 0 points east, terminal 1 south, terminal 2 west and terminal 3 north. Each wrench turn rotates this ordering. Bipolar components use terminals 0 and 2. Logic/analog output is terminal 0; their inputs are ordered 2, 1, 3. The expression processor exposes A, B, C on terminals 1, 2, 3 and normalizes signals by 5 V. Unconnected logic/analog inputs follow the original functions' nullable-input behavior.

## Settings

The value field controls the source voltage, source current, resistance, capacitance (farads), inductance (henries), transformer ratio, relay threshold, amplifier gain, filter cutoff (Hz), or PAL truth-table bit mask, depending on the device. Wireless channel names must match exactly. Only settings consumed by that device are shown.

For a PID regulator, the expression field accepts `Kp,Ki,Kd`; for a summing unit it accepts three comma-separated gains. The processor uses the original expression parser and A/B/C inputs. Only finite expressions/parameters should be used; invalid numeric configuration is rejected and formula output is limited to the 0–5 V signal range.

Battery charge and life survive saving, chunk reload and pickup. Capacitor voltage and inductor current survive circuit rebuilds and world saving, but are deliberately not restored after pickup. Meter energy is accumulated absolute electrical energy through the device, not a signed grid import/export balance. Cable destruction, battery aging and thermal behavior are experimental approximations.

The optional `config/eln/eln.json` uses the original hierarchical setting names consumed by the migrated code. It is read when the mod starts and is not generated automatically. Most old settings have no effect because the corresponding systems are absent. Example:

```json
{
  "balance": { "storage": { "batteryCapacityFactor": 1.0 } },
  "simulation": { "watchdog": { "destruction": { "thermal": true } } }
}
```

## Build from the supplied source

Run commands **inside `ElectricalAge-main/forge-1.19.2`**, not the original project root. Install Java 17; the included wrapper downloads Gradle 8.8. Python 3 is needed for content regeneration, but the generated resources are already included for a normal build.

```sh
cd ElectricalAge-main/forge-1.19.2
./gradlew build
./gradlew runGameTestServer
./gradlew runClient
```

On Windows use `gradlew.bat`. The installable result is `build/libs/electrical-age-1.19.2-0.2.0-port-all.jar`. An initial build downloads ForgeGradle, Minecraft and Maven dependencies and needs network access. `--offline` works only after that cache has been populated.

To regenerate migrated code/resources from the original source retained one directory above:

```sh
python3 tools/migrate_core.py
python3 tools/migrate_device_math.py
python3 tools/migrate_assets.py
./gradlew generateLangFiles
python3 tools/audit_legacy.py
./gradlew build runGameTestServer
```

These scripts overwrite the native generated files. Make durable adaptations in the generators as well as the generated code. The handwritten platform implementation is under `src/main/kotlin/mods/eln/modern/`; device mathematics remain in original package names. Do not mechanically replace imports across the legacy project: registration, rendering, packet, world, inventory and persistence APIs require actual redesign.

## Recipes

Native crafting recipes are a small experimental set, not the original progression. The furnace uses vanilla smelting. The other processors use the native `eln:processing` datapack recipe type; see the included `data/eln/recipes/` examples for the exact schema. This permits expanding processing recipes without rebuilding the mod. Recipe keys must remain unique.

## Troubleshooting

- A missing Kotlin `Intrinsics` class usually means the thin JAR was installed. Use the `-all.jar` only.
- If Minecraft reports a missing Forge version, install the tested 43.5.0 build for 1.19.2.
- If a circuit has no current, check the return/ground path, opposing terminals, switch state and orientation. The restored model terminals indicate direction; device behavior still has the limits recorded in PORT_STATUS.md.
- Server logs contain a specific error if a circuit simulation is paused after a numerical exception. Changing topology retries the circuit. Include that stack trace and a small reproduction when investigating.
- The full original mod still cannot be built for 1.19.2 by invoking its root Gradle build. This archive intentionally contains both the unchanged old project and the separate native adaptation.
