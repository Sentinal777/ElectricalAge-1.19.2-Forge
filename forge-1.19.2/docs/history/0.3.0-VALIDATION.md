Electrical Age 0.3.0 preview — executed test report, October 14, 2026

RESULTS
Java 17 / Minecraft 1.19.2 / exact Forge 43.5.0 build passed. All 178 JUnit tests passed, zero failures/errors/skips. The recovered baseline had 168 tests; ten meaningful numerical/conservation/display/migration tests were added. The retained suite includes expression parsing, MNA topology/matrix/source behavior, RC/RL behavior, transformer relationships, batteries, solar and geometry. Tests validate their cases, not complete original parity.

23 native Minecraft GameTests passed without BCCE. With the published BCCE 8.0.23 file 9035804, all 29 required tests passed: the same 23 native cases plus six actual BCCE assemblies/capability cases. Counts are not added together as 52 independent tests. No skipped case is counted as passed.

Native world cases: analytical resistor/disconnection; breaker trip/reset; furnace input consumption/smelting; macerator datapack recipe; AND changing inputs; wireless channel separation; capacitor topology rebuild; battery discharge/NBT; floating series solar panels; third gate input; flip-flop state reload; analog sample/hold; surface placement/selection/support loss; machine power/pause visual state; direct signal controls; display independent input/dot/strobe, dye and persistence; conductor loss/thermal overload; conductor overvoltage; fractional FE/transfer budget; FE input powering a real resistor/persistence; sided inventory validation; electrical motor/shaft generator/split; kinetic rolling recipe.

Actual BCCE cases: native MJ simulation/limits/save; creative engine supplying ELN resistor and disconnecting; ELN source/converter supplying a real quarry's MJ store; wooden item pipe supplying a powered ELN furnace; underside item pipe extracting output to chest and preserving input; BCCE tank/wooden fluid pipe supplying an ELN fuel generator. Quarry digging was not asserted. Wooden pipe extraction was powered via the published pipe's actual receivePower API; a separate engine-driven complete factory was not tested.

PRODUCTION INSTALLABLE-JAR CHECK
The normal reobfuscated Jar-in-Jar artifact was loaded in a separate dedicated Forge 43.5.0 server, using Java 17, localhost-only binding and a new QA world. No development classes/deobfuscated mod were substituted. Without BCCE: two full starts, 50 V/cable/100 Ω resistor (~0.499845 A), removal (0 A), FE production and battery discharge, save/stop/restart. Stopped FE energy and battery charge restored exactly. No missing BCCE class or paused-circuit error occurred.

With the published BCCE JAR: production co-load passed, native MJ from an actual creative engine drove ELN's resistor, and a physical loop of two opposite-mode converters repeatedly exchanged electrical energy and native MJ without increasing its seeded 1,000 FE. The loop operated and its total remaining buffered energy fell below the initial amount. This extends the unit accounting tests with a real production assembly. It does not establish every possible mod/scale/efficiency combination.

CLIENT / SINGLEPLAYER
Actual Minecraft client and integrated server loaded an isolated copy of the newly created QA world. All 122 registered component variants were placed and rendered; original OBJ/textures loaded. Converter direction and display range were changed through real server-authoritative menus/packets and confirmed on the client. Gallery, shaft gallery and both GUI screenshots are included. The QA run used a test-only Java agent to bypass this host's stalled GLFW event pump and pace rendering. The agent/ClientSmoke classes are absent from the delivered JAR. This was automated client rendering and integrated-server testing, not a manual mouse/keyboard survival playthrough. GUI visual inspection passed; audio playback, all orientations/animations and normal manual controls were not fully exercised.
